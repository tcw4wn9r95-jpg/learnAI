# 🚀 LearnAI

A fun, mobile-first web app that turns any AI topic into a short course tailored to **your career**: simple theory, a practical worked example, use cases from your own roles (including International Supply Chain at Blue Origin), a copy-ready prompt to try, and a quiz. Earn XP, keep a streak and collect a cheat sheet at the end.

## Use it on iPhone
1. Open the GitHub Pages URL in **Safari**.
2. Tap **Share → Add to Home Screen**. It opens full-screen like a native app.
3. Go to **Profile** and add your roles, plus your Anthropic API key ([console.anthropic.com](https://console.anthropic.com/settings/keys)).
4. On **Home**, type a topic (or tap a suggestion / 🎲 Surprise me) and hit **Build course**.

No key yet? Tap **Try a sample course** to play a built-in supply-chain course.

## How it works
- Pure static site (HTML/CSS/JS), no build step. Hosted on GitHub Pages via `.github/workflows/pages.yml`.
- Courses are generated by Claude (default: Claude Opus 5.5) through the official Anthropic JS SDK, called directly from your browser with structured JSON output.
- Your profile, API key, courses, XP and streak are stored **only in your browser's localStorage**. The key is sent only to Anthropic.
- Works offline for courses you've already generated (service worker).

## Safety note
Don't enter export-controlled (ITAR/EAR) technical data or proprietary company information into your profile or topics. The course generator is instructed to keep examples generic and fictional and to model safe AI use.

## Deploy
Push to `main`. In **Settings → Pages**, set **Source: GitHub Actions** (once). The site is published at `https://<user>.github.io/learnAI/`.
